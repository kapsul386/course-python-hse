# Homework 4 — Flask Server


Сервер запускается на порту, указанном в `.env`.

---

## Requirements
- Python 3.9+
- make

---

## Installation

Установка зависимостей и создание виртуального окружения:

```bash
make install
````

---

## Run server

Запуск сервера:

```bash
make run
```

Порт и режим отладки настраиваются через файл `.env`.

Пример `.env`:

```env
PORT=5050
DEBUG=True
```

---

## Available requests (API)

Базовый адрес:

```
http://127.0.0.1:<PORT>
```

### 1. Проверка работоспособности сервера.

**Пример запроса:**

```bash
http://127.0.0.1:5050/
```

**Ответ:**

```
My server
```

---

### 2. `/author` Возвращает информацию об авторе.

**Пример запроса:**

```bash
http://127.0.0.1:5050/author
```

**Ответ (JSON):**

```json
{
  "name": "Dmritrii",
  "course": 2,
  "age": 19
}
```

---

### 3. `/sum` Вычисляет сумму двух чисел, переданных через query-параметры.

**Формат запроса:**

```
/sum?a=<number>&b=<number>
```

**Пример:**

```bash
http://127.0.0.1:5050/sum?a=2&b=3
```

**Ответ (JSON):**

```json
{
  "sum": 5.0
}
```

#### Ошибки

* Если параметры `a` или `b` отсутствуют — возвращается ошибка `400`
* Если параметры не являются числами — возвращается ошибка `400`
